# ADR 0002 — Ноль внешних зависимостей, включая тесты

**Статус:** принято (этап 0)

## Решение

Запрещены любые сторонние библиотеки: движки (Blink/WebKit/Gecko/Servo/V8/SpiderMonkey/
QuickJS/WebView/Electron/CEF), а также «мелкие удобства» (gtest, fmt, nlohmann::json).
Разрешены: стандартная библиотека C++20; с этапа 3 — SDL2 только для окна и ввода; при
необходимости — системный TLS и zlib (решение отдельным ADR на этапе 1).

## Почему

1. ТЗ требует «своё ядро»; чем меньше внешних слоёв, тем сложнее случайно протащить готовый
   парсер или шейпер.
2. Среда разработки без сети: `make test` должен работать на чистой машине, а `FetchContent`
   и пакетные менеджеры — нет.
3. Свой тест-фреймворк — ~180 строк, окупается временем сборки и независимостью от версий.

## Последствия

- inflate (gzip/PNG) пишем сами; PNG-декодер опирается на свой inflate.
- Растеризация шрифтов, shaping, bidi — свои.
- Для каждой новой зависимости нужно ADR с обоснованием и оценкой рисков.
