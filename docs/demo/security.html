Security model

Same-Origin Policy, CORS for XMLHttpRequest, Content-Security-Policy, mixed-content blocking and an opaque origin for local files.

blocked Inline script under script-src 'self'
  • The script that would replace this heading never executes.
  • The devtools panel lists it as blocked by Content-Security-Policy.
blocked Cross-origin read without Access-Control-Allow-Origin
  • The request is refused before the body is exposed to the page.
  • Reason code surfaces as cors.allow_origin_missing.
opaque This page is file://
  • Its origin is null: no cookies, no cross-origin reads.
  • localStorage is scoped to this directory only.
