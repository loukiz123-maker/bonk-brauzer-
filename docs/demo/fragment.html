Fragment parsing: innerHTML with a real context

Every box below was filled by element.innerHTML = … in the engine's own JS. The context element decides the tokenizer state and the insertion mode — the same fragment algorithm the html5lib corpus measures.

td context drops a stray row

cell.innerHTML = '<tr><td>x</td></tr>y'

tr context grows cells

row.innerHTML = '<td>a</td><td>b</td>'

table context inserts tbody

table.innerHTML = '<tr><td>t</td></tr>'

textarea context is RCDATA

area.innerHTML = '<b>not bold</b>'

div context: misnested <b>, <em>

box.innerHTML = '<p><b>1<em>2</b>3</em>'

context is never popped

box.innerHTML = '</div><b>kept</b>'
