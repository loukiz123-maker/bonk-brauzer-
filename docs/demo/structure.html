template contents are not laid out

<template><p>hidden</p></template>

frameset document

<p><frameset><frame>

A <frameset> replaces the still-empty body, so this document has no <body> at all. The engine parses it; it does not render frames yet.

scope boundaries

<div><template></div>Hello

</div> is ignored: <template> is a scope boundary, so "Hello" lands inside the template, not after the div.
